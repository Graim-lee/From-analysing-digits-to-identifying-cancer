This project is a school project where my team and I had to analyse images step by step. 
First we recognized digits, then we analysed colored picture and finaly we applied a model on breast cancer pictures. 

You can see the whole project through the jupyter notebook main.ipynb. The file got the explanation step by step of the projet. To lauch it completely, you will need for the last part to download on your own the dataset from the following link: https://www.kaggle.com/datasets/awsaf49/cbis-ddsm-breast-cancer-image-dataset. This dataset contains images of breast cancer and is too big to be uploaded on gihub. You may also want to read the subject in the file Projet_anglais.pdf

A improved version focused on the final part, breast cancer, is comming and will be found in the file cancer.ipynb
